# Notices

This is an unofficial community port. LineageOS, AOSP, pjgowtham and the upstream projects credited in CHANGES.md provide its foundations. Realme/Oplus and their suppliers own the original stock applications, libraries, models and assets.

Each upstream component keeps its own copyright and license. Kernel source and license texts accompany the release. Project patches identify the changes applied to the pinned sources. This repository introduces no blanket relicensing of third-party code or OEM binaries.

The public repository contains source references and compatibility work. Release downloads include the built ROM and separately chosen stock-app ports. Use the download's checksums and version-specific installation notes.
