# Report an issue

1. Search existing issues and [known problems](RELEASE_NOTES.md).
2. Choose the [ROM, Camera, Photos or Clock form](https://github.com/wjdob/lineageos-realmegt2pro/issues/new/choose). The form adds the component label.
3. Add `[24.0]` or `[23.2]` to the title and select the version. Maintainers add the version label.
4. Include the ROM/app versions, model, stock firmware/region, optional packages and any root or system changes.
5. Give numbered steps, expected and actual results, frequency, and the last working version if known. Report one problem per issue.
6. Attach short logs or screenshots if useful. Remove account details, IMEIs, credentials and private media. Keep partition backups private.

Use the ROM form for recovery, hardware or Google integration problems. Note boot
failures and possible data loss in the impact field. Update an existing report
when you find more information.

For code contributions, use the relevant [source repository](SOURCES.md).
Feature requests should explain the use case and desired result.
